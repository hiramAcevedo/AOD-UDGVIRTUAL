# AOD - All Office Design

Sitio web moderno para la tienda de mobiliario de oficina AOD, construido con Next.js y Tailwind CSS.

## Características

- Diseño moderno y responsivo
- Navegación intuitiva entre categorías de productos
- Visualización optimizada de imágenes
- Interfaz de usuario minimalista y elegante
- Optimizado para dispositivos móviles y de escritorio

## Tecnologías utilizadas

- Next.js - Framework de React para aplicaciones web
- Tailwind CSS - Framework de utilidades CSS
- React - Biblioteca de JavaScript para construir interfaces de usuario
- Vercel - Plataforma para despliegue

## Cómo iniciar el proyecto

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/aod-nextjs.git
cd aod-nextjs
```

2. Instala las dependencias:
```bash
npm install
```

3. Ejecuta el servidor de desarrollo:
```bash
npm run dev
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

## Despliegue en Vercel

La forma más sencilla de desplegar esta aplicación Next.js es utilizando la plataforma [Vercel](https://vercel.com), creada por los mismos desarrolladores de Next.js.

1. Importa tu repositorio a Vercel.
2. Vercel detectará automáticamente que se trata de un proyecto Next.js y aplicará la configuración óptima.
3. Tu aplicación estará disponible en cuestión de minutos.

## Estructura del proyecto

- `/src/app` - Páginas y rutas de la aplicación
- `/src/components` - Componentes reutilizables
- `/public/images` - Imágenes y recursos estáticos
- `/public/icons` - Iconos utilizados en la aplicación
